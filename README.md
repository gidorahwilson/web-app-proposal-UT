# web-app-proposal-UT
Web aplikasi survei mahasiswa berbasis AI yang tidak hanya mengumpulkan jawaban, tetapi menganalisis opini mahasiswa secara otomatis menjadi insight yang bermakna.

Project ini menunjukkan bagaimana survei akademik tradisional bisa ditingkatkan menjadi AI Insight System menggunakan Ruby Sinatra dan integrasi AI API.

🚀 Fitur Utama
Form survei online (pilihan & opini teks bebas)
Penyimpanan jawaban ke database
Analisis AI otomatis terhadap jawaban teks:
Sentiment (positif / netral / negatif)
Ringkasan opini keseluruhan
Deteksi keluhan utama
Rekomendasi perbaikan otomatis
Halaman hasil analisis (tanpa login, tanpa role admin)
UI sederhana, fokus ke insight
🧠 Konsep AI pada Sistem

Berbeda dengan survei biasa yang hanya menampilkan grafik, sistem ini menggunakan AI untuk:

Membaca opini panjang mahasiswa
Menyimpulkan inti permasalahan
Menghasilkan ringkasan otomatis
